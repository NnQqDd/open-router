# Text datasets for TTS spoof generation

Checked: **2026-10-31**. **Seven text datasets**, grouped into **Pure EN** and **VI**, for extracting text to synthesize spoof samples with TTS models. Selection favors text corpora covering varied topics and multi-domain translation datasets. **VI** includes Vietnamese prose, Vietnamese containing English, and translation datasets with a Vietnamese side. English counterparts from translation datasets can also supply Pure EN prompts; each dataset appears once in this list.

Sizes are publisher-reported release/subset sizes **before filtering, segmentation and deduplication**. Sentence pairs, records, conversations, tokens and file sizes are different units. Counts are not guaranteed numbers of unique, usable TTS prompts.

Pure EN describes accepted English utterances after filtering. VI accepts Vietnamese text with or without English; there is no separate purity or code-switching requirement. Exclude Japanese-language content from selected synthesis inputs. Source language tags alone do not establish sentence-level language purity.

For spoof experiments, split and deduplicate source texts before synthesis, keeping every voice/model rendering of a text in the same partition. Keep both sides of a translation pair in the same partition, and check overlap between corpora. Use the same prompt distribution across TTS models; when comparing bona fide and spoof speech, match text/domain distributions so vocabulary does not reveal the label. Preserve source IDs where available, original text and the exact normalized synthesis input. If published test splits serve as evaluation, keep them held out.

Counts and fields are sourced from the linked publisher pages, dataset cards and file listings. Gated or uninspected file schemas and unspecified licenses are explicitly identified. No full corpus download, independent full recount or utterance-level language audit was performed for this shortlist. The accompanying CSV contains the same seven entries.
